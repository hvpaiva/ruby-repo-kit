# Code of conduct

Treat contributors and users respectfully. Discuss ideas and behavior without
personal attacks. Harassment, discrimination, threats, sexual harassment, and
publishing another person's private information are unacceptable.

These expectations apply in project issues, pull requests and other project
spaces. Maintainers may remove inappropriate content or restrict participation,
considering the context and severity of the behavior.

Report concerns privately to contact@hvpaiva.dev with relevant context and links.
Maintainers will handle personal information discreetly and consider reports
without retaliation. This is a project-specific policy; it does not imply a
staffed response service.
